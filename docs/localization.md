# 本地化

语言资源位于 `src/main/resources/assets/tacz_aos/lang/`。按用户提供的 `lang.zip` 语言类别补齐，共 20 种语言，每种包含与 `en_us.json` 相同的 29 个翻译键。

附件中的 `tr-TR.json` 和 `tr_tr.json` 对应同一种语言，统一为 Minecraft 使用的小写下划线代码 `tr_tr`。附件仅用于确定语言类别，不导入 TACZ 本体的翻译键。

覆盖内容：测距仪与战术收集腰带名称、腰带装备与功能说明、枪声与子弹掠过字幕、远距离击杀提示、命令状态消息及资格判定原因。技术标识符（枪械 ID、状态代码、FULL、tick 等）保留其含义。

瞄准镜内部显示的测距、风速、湿度等信息按用户要求保持原样，没有新增翻译键或修改 HUD 实现。

维护时应保持 UTF-8 编码及所有键完整；`%s` 的数量与顺序须与调用一致。击杀消息使用 `%1$s`（死亡玩家）、`%2$s`（击杀者）、`%3$s`（距离），允许根据各语言语法调整显示顺序，不可改动参数含义。

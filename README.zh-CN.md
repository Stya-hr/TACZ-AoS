# TACZ: Art of Sniping

[English](README.md) | **简体中文**

**TACZ: AoS** 是为 TACZ 添加拟真弹道和远距离狙击玩法的扩展模组。作者：**Sange**。

允许玩家从超远距离狙击其他实体。

## 安装要求

Minecraft **1.20.1**、**Forge 47.3.0 或更新版本**、Java **17**，以及 [TACZ 官方 Forge 1.20.1 版](https://modrinth.com/mod/timeless-and-classics-zero)（**1.1.8-hotfix**，支持范围低于 1.2）。客户端与服务端都需要安装 AoS 和 TACZ。

## 添加了什么

- **测距仪：** 两格高的三脚架设备，在其 **3 格以内**可启用开镜狙击功能。它只负责启用功能，测距方向由玩家的瞄准决定。
- **战术收集腰带：** 装备在裤子槽或已有的 Curios 腰带槽。使用**任意 TACZ 枪械**击杀后，掉落物与经验会转移到脚下，也支持通过正常死亡掉落流程产生的其他模组物品。无需测距仪或开镜。
- 远处实体的加载、模拟与渲染，镜内测距、风速和湿度读数，以及弹道烟迹。
- 多人游戏中的子弹掠过声、延迟传来的远处枪声，以及特殊远距离玩家击杀提示。
- 真实尺度重力、可选的风偏与湿度影响，以及可配置的枪械初速和阻力覆盖。这些弹道物理也会影响狙击模式之外的普通 TACZ 动能弹。
- 使用白名单枪械匍匐时，随机散布归零，并抑制开镜待机晃动；射击后坐力仍然保留。

两个物品均位于 TACZ 枪械工作台所在的创造模式物品栏。合成方式如下，`.` 表示空位：

| 测距仪 | 战术收集腰带 |
| --- | --- |
| `G D G` | `. D .` |
| `. I .` | `L R L` |
| `I . I` | `. A .` |

`G` = 无色玻璃板，`D` = 钻石，`I` = 铁锭，`L` = 皮革，`R` = 红石粉，`A` = 金锭。

## 怎么游玩

1. 先探索要进行狙击的区域。使用 [NHblock-Johnsnow 的 NeoVoxy 分支](https://github.com/NHblock-Johnsnow/neo-voxy)可以看见原版渲染距离以外的地形。
2. 放置测距仪，保持在其 **3 格以内**，使用白名单枪械并安装白名单瞄准镜。
3. 开镜并稳定瞄准目标附近的可见地形。AoS 会加载并模拟目标区域，使远处生物、玩家和 TACZ 标靶能够显示并接受射击。
4. 参考镜内信息，抬高枪口补偿下坠，并修正风偏。调整瞄准时，目标区域会短暂保留；已接管的子弹在飞行期间也会维持目标区域。

所有开镜倍率均可启用狙击功能。读数仅显示在受支持的光学瞄准镜视图中，备用机瞄与开放式瞄具不显示。默认支持 **AWP、M95、M107、M700 和春田 1873**，以及数款 TACZ 瞄准镜。

未安装 Voxy 时，原版渲染距离以外的地形不能作为新的加载目标。视线经过未生成地带时，也不会加载远端目标。

## 性能开销与瞄准取舍

AoS 采用少量目标区域的加载方案，不会为了远距离狙击而加载子弹整条飞行路径上的全部区块。

**为什么不直接沿弹道加载，而要先用准星选点？** 准星对应玩家的直线视线，因此模组可以直接利用 Voxy 已渲染的 LOD 深度，快速取得画面中的可见地表位置，无需加载途中区块。但受下坠和风偏影响的弯曲弹道并不沿这条视线前进，还可能经过相机看不见的地形背后；现有 LOD 深度接口无法仅凭该画面可靠确定曲线的首次碰撞点。若要先精确计算弹着点再加载，就需要获取沿途直到首次命中位置的碰撞数据，例如读取或缓存相关区块的地形快照，并逐段检查碰撞。维护和读取这些数据会增加开销，也可能使超远距离选点出现等待。因此，本模组采用以下算法：

1. **准星负责申请加载。** 玩家满足狙击条件并稳定开镜时，模组会申请加载准星指向的可见地表附近区域。超出原版渲染距离时，利用 Voxy 已渲染的 LOD 表面确定候选位置。这代表该表面在 LOD 画面中可见，并不等于对沿途最新真实地形进行了精确无遮挡检查。
2. **准星移开后，目标区域仍会短暂保留**，默认约 3 秒，为调整瞄准留出时间。
3. **预测弹道负责保留目标区域。** 模组会根据枪械弹道参数与环境影响，周期性重算弯曲弹道。如果预测会在已有目标区域内命中方块或实体，就续期保留该区域。弹道线不会主动加载新区域，也不是让沿途所有已加载区块都保持加载。

这解决了补偿下坠时的一个问题：瞄准生物后上抬准星，准星可能指向生物后方更远的山坡。此时虽然准星会申请加载远处区域，但只要预测子弹仍会落在原目标区域内，就能继续保留原目标。**如果抬得太高，预测弹道可能完全越过原目标区域**；保留时间结束后，目标生物就可能从视野中消失。这种情况下属于正常现象：重新将准星指向目标原来的位置或附近地形，等目标出现后，再尝试少上抬一些。

可以概括为：**准星触发加载，预测着弹点维持加载。** 区块加载、实体 AI 和同步仍有开销，多名玩家同时狙击时尤为明显，但加载请求、活跃区域数量和预测计算均受预算控制。其精度取舍是明确的：狙击子弹**只在保留的目标区域内判断碰撞**，途中其他区域的障碍物在边缘情况下可能被穿过。

例如，准星能看见目标，但较低的弯曲弹道实际上会撞上中途的山脊；若山脊位于保留的目标区域之外，子弹就可能穿过它。AoS 接受这种“视线可见、实际弹道受阻”的边缘情形，以换取响应更快、开销更低的远距离瞄准体验。它对平衡性的影响取决于地形和玩家的使用方式；目标区域内的地形仍会正常挡弹。

## 配置

Forge 实际使用 `<存档>/serverconfig/tacz_aos-server.toml`，首次进入世界时自动生成。多人游戏应修改**服务端**的这份文件，修改后重启世界或服务器。`config/` 下自动生成的文件是参考模板；如需为新建世界设定默认值，将修改后的模板复制到 `defaultconfigs/tacz_aos-server.toml`。

添加其他 TACZ 枪包时，在 `[eligibility]` 的 `guns` 中追加**枪械 ID**，在 `scopeRules` 中追加**瞄准镜配件 ID**。使用 `pack:rifle` 这样的枪包 ID，而不是 TACZ 的通用枪械物品 ID；保留仍需使用的原有条目。例如：

```toml
[eligibility]
guns = ["tacz:ai_awp", "your_pack:sniper"]
scopeRules = ["tacz:scope_mk5hd|5,25,1.25", "your_pack:scope"]

[limits]
maxDistance = 1024
```

将 `your_pack:*` 替换为实际安装的枪包 ID。瞄准镜还可按枪包顺序填写真实倍率，例如 `your_pack:scope|4,8,1`；这是投影参考数据，**不是允许倍率的限制**。客户端读取枪包实际的倍率与视图数据；使用自定义渲染方式的瞄具，其镜内读数可能需要额外适配。

`limits.maxDistance` 控制最大目标距离，单位为格，**默认 1024**，可改为 **2048** 进行更远距离的射击。默认也限制狙击子弹的累计飞行距离，因此弯曲弹道会比直线消耗更多射程。`ballistics.maxDistance = 0` 跟随此上限，正数只能进一步降低子弹射程。提高距离不会取消地形条件与加载预算限制。

## 兼容性

| 可选模组 | 兼容功能 |
| --- | --- |
| [**NeoVoxy（NHblock-Johnsnow）**](https://github.com/NHblock-Johnsnow/neo-voxy) | 利用远处 LOD 地形选取目标，由 AoS 补充目标区域实体。本分支针对 Forge 1.20.1 客户端版 NeoVoxy 0.3.3，需另装 Embeddium 0.3.31+。不保证其他 Voxy 分支兼容，建议使用此分支。 |
| **Curios** | 收集腰带可放入已有的 `belt` 功能槽，不新增槽位；外观槽不生效。支持 5.14.1–5.x。 |
| **ParCool / Crawl on Demand** | 识别其匍匐状态，为白名单枪械启用零散布与待机晃动抑制。 |

可选安装 [Oculus](https://modrinth.com/mod/oculus) **1.8.0**，支持 Forge 1.20.1 光影下的测距、远处实体／标靶及弹道烟线。仅客户端需要安装；不安装时仍使用普通渲染。需要显示远处 LOD 地形时，光影包本身也必须支持上述 NeoVoxy 分支。已测试 **Complementary Unbound r5.8.1** 与上述 NeoVoxy／Embeddium 组合，不保证所有光影包兼容。光影下不绘制单独的发光弹头圆点。

请选择适用于 Minecraft 1.20.1 Forge 的版本，并安装各可选模组自身的前置。使用标准枪械与弹丸接口的其他 TACZ 枪包可通过配置扩展；自定义弹丸或渲染器可能需要额外适配。本模组会保留其他玩家和区块加载器已有的加载请求。

**不支持同时使用：[Tacz Bullet Improvement](https://modrinth.com/mod/tacz-tacz-bullet-improvement)。** 其公开说明将 TACZ 的飞行子弹替换为瞬时射线命中，与 AoS 的飞行时间、下坠、风偏和着弹预测机制冲突。请勿搭配使用；Minecraft 版本相同也不会消除这项机制冲突。
